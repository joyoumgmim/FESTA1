# 📈 FESTA - 테스타 매매법 한국 주식 분석 대시보드

테스타(Testa)의 매매 철학과 5/25/75일 이동평균선 기법을
**모바일/PC 모두 최적화된 Streamlit 웹 대시보드**로 구현했습니다.

---

## 🆕 v2.0 주요 업데이트

### 📱 모바일 반응형 최적화
- 자동 1열 레이아웃 (모바일) / 다중 컬럼 (PC)
- 차트 크기 자동 조정
- 사이드바 기본 접힘 (모바일)
- 손가락 친화적 버튼 크기
- 사이드바에 **📱 모바일 모드** 토글

### ⏱️ 분석 기간 1년 기본값
- 75일 이평선이 안정적으로 그려지는 최소 기간
- 큰 추세와 단기 타점 균형

### 🔍 다중 기간 비교 분석
- 1년 추세 + 6개월 타점 동시 표시
- 두 기간 모두 매수신호일 때 강력 추천 표시

## 🚀 VS Code에서 실행하기

```bash
# 1. 폴더 열기 (festa_app)

# 2. 가상환경 생성 (권장)
python -m venv venv
venv\Scripts\activate    # Windows
source venv/bin/activate # Mac/Linux

# 3. 패키지 설치
pip install -r requirements.txt

# 4. 실행
streamlit run app.py
```

## 📱 모바일에서 사용하기

### 1. 사이드바 열기
화면 좌측 상단의 **>** 또는 **≡** 버튼을 누르면 메뉴가 열립니다.

### 2. 모바일 모드 켜기
사이드바에서 **📱 모바일 모드** 체크박스를 켜면:
- 차트가 작은 크기로 표시
- 메트릭 카드가 세로 1열로 정렬
- 폰트와 패딩 자동 축소

### 3. 가로 화면 추천
차트를 자세히 보려면 핸드폰을 가로로 돌리세요.

### 4. 핀치 줌으로 확대
차트는 핀치 동작으로 확대/축소 가능합니다.
